## 口径

- 固定CV764、MVU TR1585、CrossVid PSS341/FSA394四道开发题；覆盖三个benchmark和单选/排序/时间定位格式，不按本轮答案选题。
- CPU先以原拼接实现分别写持久卷和本地临时盘；不改编码、尺寸、帧时间、颜色和校验。交替A/B顺序，比较完整MP4 SHA、耗时及每0.5秒采样的文件占用。短暂峰值可能被漏采，采样峰值不是容量上限保证。
- GPU测试共16次rollout：两个方法各四题×两种存储。每个配对固定同一单卡、副本和模型参数；一组8H100中RSI占0–3、LensWalk占4–7，每卡TP1/C1。保持各自原提示、输出预算、图像规则及600秒HTTP等待；不是每方法8卡全量吞吐试验。
- 为单独测量媒体读取对推理的影响，GPU本地臂复制已验证字节相同的输入到`/work`，复制耗时单列，完整题内复用，配对结束释放。本地生成的视频与该文件在CPU试验中逐字节一致。CPU生成与GPU推理分开测量，不能把两种机器上的耗时相加冒充实测端到端流水线。
- 逐次比较实际prompt token、图片载荷哈希、完整输出token和最终答案；另记录原请求字节哈希及并发工具回包顺序。正常未收尾或空答案不修复；工程失败不能计为有效一致性比较。不开Judge、不评准确率。
- 完整NC80另用CPU做双存储长视频实验，避免模型GPU等待转码。没有实现LRU淘汰或预取；先验证最小临时文件寿命方案。
