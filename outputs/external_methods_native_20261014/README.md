# 原分辨率、原帧率拼接设置

用户要求只取消拼接预处理中的缩放及FPS转换，保留模型输入的既有限制。后续仅评测Video-RSI和VAM，Meta不再提交。

- 通过视频码流复制拼接，不缩放、不填边、不重编码、不补帧/抽帧；不同片段可保留不同分辨率和帧率。
- 统一容器时间刻度到微秒，不改变每个片段的帧时间间隔。每段以首个视频包的PTS归零，并在拼接后核对完整视频包PTS序列。
- 时间范围以实际视频包计时；原始容器可能包含音频尾部或提前开始的音频时间，不能直接用容器总时长作为下一视频偏移。
- 原问题、选项与拼接说明进入prompt；题目和答案仍用原视频相对时间。标签独立保存。
- 本轮沿用旧33题manifest，不重新抽样；媒体与元数据仅留Modal。新目录为`devbox/external_methods_native_20261014/`。

合成CPU检查已验证H.264与MPEG-4的混合尺寸/帧率输入，50/50帧的解码像素、尺寸和时间不变。实际33题准备正在`prepared_r2`执行：R1因容器时长和视频包时长不一致被拒绝，失败材料保留；R2改为逐包计时和校验，没有用重编码绕过。

原始输入中的编码在每题内一致；遇到不同编码的同题输入会明确报错，不会静默转换。当前模型侧设置未改变：RSI抽帧宽度448；VAM图片面积上限448×448，仍按其原流程抽帧、生成记忆及检索。

没有将旧33题模型输出当作新预处理结果；当前改动验证的是媒体准备与提示词组装，尚未在新媒体上重新测模型准确率。
