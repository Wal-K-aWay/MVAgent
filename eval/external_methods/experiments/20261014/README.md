# Historical external-method recovery scripts

entrypoints have been removed from active source. Original scripts, predictions
and scoring records remain in the frozen runs under
`devbox/external_methods_20261014`; do not treat this directory as a VAM launcher.

entrypoints and validation status are documented in the [adapter README](../../README.md).
The earlier three-method finalizer is also preserved in Git commit `16d694f`.
