# 单张Global时间正文的自然入口对照

英文卡片见[manual_global_temporal_single_bank.json](../src/skill_evolution/configs/manual_global_temporal_single_bank.json)。保留已冻结简短temporal正文、ID `3`与`initial/evidence` stages；库只含此卡，将`when_to_use`改成覆盖所提供视频的问题。Selector仍可弃选，Actor、选择机制和视频侧空库不变。

它检验高均值单正文能否通过现有自然选择机制部署，作为多卡题目路由的必要对照。不要求Selector强选，也不假设泛化收益；该宽入口不是已学习的效用规则。先跑原Train80/Cal40，Cal严格胜空库后才考虑原Gate176。方案在该对照的结果及365题确认完整结果之前确定；不读取Gate逐题反馈修改卡。

完整中文镜像：

- `when_to_use`：在回答有关所提供视频的问题时使用。
- `strategy`：对于跨视频时间关系，分开锚点事件、它的源时间，以及所求目标状态或区间。先取得锚点的可见身份、动作和相关前后状态，再使用它。把已返回的参考事实传入之后的目标指令；并发 VideoAgent 调用不能共享新报告。只有同步关系明确时才使用相同时间戳。对等价步骤，匹配功能与状态变化，再核实目标两端边界；绝不复制参考时长。对缺失中段或排序问题，观察相邻的已提供状态并推断过渡，不能声称看到了缺失片段。粗略锚点的不确定性可能改变答案时，细化定位。联合观察至少包含两个视频和合法局部片段，不提供 `fps`。依据受支持的证据按要求格式回答。

正文未作任何改写；选择入口同时改变库大小和候选竞争关系，因此不把它解释为单字段消融。它也不证明多卡有必要，应与空库、相同正文固定注入和自然三卡结果共同报告。
