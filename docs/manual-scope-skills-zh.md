## 卡4的strategy（完整镜像）

仅当所求答案需要组合可在各相关视频中独立核实的条件时，应用这种聚合。如果所求结果是统计单视频内的重复事件，或需要联合证据建立跨视角身份对应，则继续使用普通证据流程及其现有动作，不应用独立视频投票。

对于可逐视频独立判断的条件，保留谓词、限定、被计数实体，以及结果是是非判断、准确数量还是完整子集。用analyze_videos传递相同的中立判据和必要定义，请求各来源的可见依据与限制。区分有支持的符合项、排除项和未知项。符合项给出计数下界，加入未知项给出上界；遗漏不等于排除。检查解决未知项是否可能改变所求结果；即使是非结果已确定，准确子集仍可能需要解决每个潜在成员。仅对重要缺口追问；收紧上下界前，先解决谓词变化或报告冲突。当所有与证据相容的结果一致时回答。若运行时更早结束，按要求格式给出证据最支持的非空答案，并在reason中说明剩余界限。
